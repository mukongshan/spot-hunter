# 景区APP项目开发任务清单（三端+六人分工）

## 一、总体架构与分工
### 三端架构

前端(Web管理端/用户端) ↓ REST API/JSON ↓ 后端(业务+数据+鉴权) ↓ REST API ↓ 鸿蒙移动端(App)

### 人员分工（6人）
| 角色    | 人数 | 主要职责                |
| ------- | ---- | ----------------------- |
| Web前端 | 2人  | 页面开发 + 接口对接     |
| 后端    | 2人  | API开发 + 数据库 + 权限 |
| 鸿蒙端  | 2人  | App页面 + 模板改造      |

---

## 二、后端任务列表（Spring Boot + MySQL）
### 后端A：基础架构（优先级高）
1. **项目初始化**
   - Spring Boot项目搭建
   - 分层结构设计（controller/service/impl/mapper/entity/dto/vo）
   - 全局返回体封装（`Result`）
   - 全局异常处理（`@ControllerAdvice`）

2. **用户与权限**
   - 用户表设计（`user`: id/username/password/role/phone/avatar）
   - 登录接口 + JWT/Session Token机制
   - 权限区分（普通游客/管理员）

3. **公共能力**
   - 文件上传（景点/轮播图片）
   - 分页查询封装
   - 接口文档（Swagger/Knife4j）

### 后端B：核心业务
1. **景区模块**
   - 景点列表/详情/搜索接口
2. **公告模块**
   - 公告发布/列表/详情接口
3. **门票与订单**
   - 门票类型管理
   - 订单表设计（状态：待支付/已支付/已取消）
   - 下单接口 + 订单查询（按用户/状态）
4. **扩展功能（加分项）**
   - 游记/攻略/评论
   - 数据统计接口（订单数/访问量）

---

## 三、Web前端任务列表（Vue3 + Element Plus）
### 前端A：页面与组件
1. **基础搭建**
   - 项目初始化（Vue3 + Router + Pinia）
   - 全局布局（侧边栏+顶栏）
   - 路由权限控制（管理员）
2. **页面实现**
   - 登录页
   - 景点管理（表格+增删改）
   - 公告管理/门票管理/订单管理页面

### 前端B：接口与交互
1. **技术实现**
   - Axios封装 + Token自动携带
   - 统一错误提示
2. **功能细节**
   - 分页查询/表单校验/图片上传
   - 搜索与筛选
3. **扩展功能**
   - 数据统计图表（ECharts）
   - 用户管理页面

---

## 四、鸿蒙移动端任务列表（基于模板改造）
### 鸿蒙端A：页面与UI
1. **基础搭建**
   - 拷贝模板工程 + 跑通示例
   - 删除冗余组件模块
2. **核心页面**
   - 首页（轮播图+热门景点+公告入口）
   - 景点列表/详情页
   - 门票列表/预订页面

### 鸿蒙端B：数据与业务
1. **网络层**
   - 替换Mock数据为真实接口
   - 统一网络封装（`network`模块）
   - 数据映射（`mapper`）
2. **用户功能**
   - 登录（简化版）
   - 我的页面/订单/订单详情
3. **扩展功能**
   - 地图定位（按需）
   - 语音播报（直接复用模板）
   - 热线拨打

## 五、三端协作接口清单（必联调）
| 接口路径                 | 方法 | 功能          |
| ------------------------ | ---- | ------------- |
| `POST /api/auth/login`   | 登录 | 获取用户Token |
| `GET /api/scenic/list`   | 查询 | 景点列表      |
| `GET /api/scenic/{id}`   | 查询 | 景点详情      |
| `GET /api/notice/list`   | 查询 | 公告列表      |
| `GET /api/ticket/list`   | 查询 | 门票列表      |
| `POST /api/order/create` | 下单 | 创建门票订单  |
| `GET /api/order/my`      | 查询 | 我的订单列表  |

---

## 六、推荐开发顺序
1. **第一阶段（基础功能）**
   - 后端：用户模块 + 景点模块 + 门票基础
   - 前端：登录页 + 景点管理页面
   - 鸿蒙：模板运行 + 首页基础

2. **第二阶段（核心流程）**
   - 后端：订单模块
   - 前端：订单管理页面
   - 鸿蒙：门票预订 + 下单流程

3. **第三阶段（联调优化）**
   - 三端联调（登录→景点→门票→订单全链路）
   - 扩展功能开发（游记/评论/统计等）

4. **最终阶段**
   - PPT演示材料准备
   - 功能演示与验收
