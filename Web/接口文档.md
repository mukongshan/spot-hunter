# 接口文档

| 模块      | 接口名称 | 请求方法 | 接口路径    | 是否鉴权 | 请求参数    | 返回说明   | 负责人 |
| --------- | -------- | -------- | ----------- | -------- | ----------- | ---------- | ------ |
| 认证      | 用户登录 | POST     | `/api/auth` | 否       | username    | token + 月 | 后端A  |
| 认证      | 获取当前 | GET      | `/api/auth` | 是       | 无          | 当前登录   | 后端A  |
| 首页      | 首页数据 | GET      | `/api/horn` | 否       | 无          | 轮播图/表  | 后端B  |
| 景点      | 景点列表 | GET      | `/api/scen` | 否       | page, size  | 分页景点   | 后端B  |
| 景点      | 景点详情 | GET      | `/api/scen` | 否       | id          | 景点详细   | 后端B  |
| 景点-管理 | 新增景点 | POST     | `/api/adr`  | 是       | 景点信息    | 新增成功   | 后端B  |
| 景点-管理 | 修改景点 | PUT      | `/api/adr`  | 是       | id + 景点   | 修改成功   | 后端B  |
| 景点-管理 | 删除景点 | DELETE   | `/api/adr`  | 是       | id          | 删除成功   | 后端B  |
| 公告      | 公告列表 | GET      | `/api/noti` | 否       | 无          | 公告列表   | 后端B  |
| 公告      | 公告详情 | GET      | `/api/noti` | 否       | id          | 公告详情   | 后端B  |
| 公告-管理 | 发布公告 | POST     | `/api/adr`  | 是       | 公告信息    | 发布成功   | 后端B  |
| 公告-管理 | 修改公告 | PUT      | `/api/adr`  | 是       | id + 公告   | 修改成功   | 后端B  |
| 公告-管理 | 删除公告 | DELETE   | `/api/adr`  | 是       | id          | 删除成功   | 后端B  |
| 门票      | 门票列表 | GET      | `/api/tick` | 否       | scenicId    | 门票列表   | 后端B  |
| 门票      | 门票详情 | GET      | `/api/tick` | 否       | id          | 门票详情   | 后端B  |
| 门票-管理 | 新增门票 | POST     | `/api/adr`  | 是       | 门票信息    | 新增成功   | 后端B  |
| 门票-管理 | 修改门票 | PUT      | `/api/adr`  | 是       | id + 门票   | 修改成功   | 后端B  |
| 门票-管理 | 删除门票 | DELETE   | `/api/adr`  | 是       | id          | 删除成功   | 后端B  |
| 订单      | 创建订单 | POST     | `/api/ord`  | 是       | ticketId, c | 订单信息   | 后端B  |
| 订单      | 我的订单 | GET      | `/api/ord`  | 是       | status      | 订单列表   | 后端B  |
| 订单      | 订单详情 | GET      | `/api/ord`  | 是       | id          | 订单详情   | 后端B  |
| 订单      | 取消订单 | POST     | `/api/ord`  | 是       | id          | 取消成功   | 后端B  |
| 文件      | 图片上传 | POST     | `/api/uplc` | 是       | file        | 图片URL    | 后端A  |

### 5. 景点管理接口（管理员）
**新增景点：**
```http
POST /api/admin/scenic
```
**请求参数：**
```json
{
  "name": "新景点名称",
  "cover": "封面图URL",
  "images": ["图片1URL", "图片2URL"],
  "location": "地点",
  "description": "简介",
  "detail": "详细描述",
  "openTime": "开放时间",
  "price": 100,
  "address": "详细地址",
  "phone": "联系电话",
  "tags": ["标签1", "标签2"]
}
```

**返回值：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 3,
    "message": "景点创建成功"
  }
}
```

**修改景点：**
```http
PUT /api/admin/scenic/1
```

**返回值：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "message": "景点更新成功"
  }
}
```

**删除景点：**
```http
DELETE /api/admin/scenic/1
```

**返回值：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "message": "景点删除成功"
  }
}
```

## 统一响应格式
所有接口返回统一格式：
```json
{
  "code": 0,           // 状态码：0=成功，其他=失败
  "msg": "success",    // 提示信息
  "data": {}           // 业务数据
}
```

**错误示例：**
```json
{
  "code": 1001,
  "msg": "用户名或密码错误",
  "data": null
}
```

**常见状态码：**
- `0`: 成功
- `1001`: 认证失败
- `1002`: 参数错误
- `1003`: 资源不存在
- `1004`: 权限不足
- `2001`: 库存不足
- `2002`: 订单状态异常
- `3001`: 文件上传失败
